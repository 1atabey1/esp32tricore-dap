Source and mode

Watched memory

Two slots (one DTU comparator set each). A slot watches size bytes from address as the selected source sees it; watch a whole struct with a larger size and the decoder separates the variables by address. Cached (0x8…/0x9…) and uncached (0xA…/0xB…) aliases are different addresses. The value filter compares the variable's value, after the mask, against [low, high].
