TriCore flash

idle ← probe trace

Takes an Intel HEX (.hex). Programs program flash, skipping sectors that already hold the image; never DFLASH. The boot mode headers are written only with the box ticked, only after the program flash verifies, and only while the device reports them UNREAD or UNLOCKED; other UCBs (SWAP, OTP, DBG, HSM, ...) are never written.
